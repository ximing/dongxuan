新增：[提示词交互优化演示](prompt-workbench.html)，对应[优化提案](../prompt-interaction-redesign.md)。这是独立的新版交互原型，可直接打开，不影响下方原有整站设计稿。

新增：[提示词富文本演示](prompt-richtext.html)，对应[富文本与 JSON 方案](../prompt-richtext-plan.md)。演示中文资料标签、JSON 存储与纯文本输出的关系；正式 Tiptap 实现与验证见[实施验收](../prompt-richtext-validation.md)。

打开 [index.html](index.html)。无需构建或连接数据库，保留同目录的 CSS、JS 和示例数据即可。当前版本：**自己用，也帮别人看；一张命盘就是一个人，不需要职业工作台。**

## 页面

- [排盘首页](index.html#/cast)：直接填写资料，右侧打开已有命盘。
- [全部命盘](index.html#/charts)：每张命盘就是一个人，可按称呼查找，也可看已归档。
- [紫微盘面](index.html#/charts/lin)：本命、指定日、月份、文字盘、保存视图和笔记。
- [提示词](index.html#/prompts)：定义模板填写项、选择命盘、当前/下一大限、多流年、连续月份、预览与复制。称呼和性别取自这张命盘。
- [梅花易数](index.html#/meihua)：独立填写问题与两个数字、可选关联一张命盘、保存会话草稿并进入提示词。
- [设置](index.html#/settings)：账号与规则的轻量入口。

旧的 `#/profiles` 会打开命盘列表。全部页面属于同一套站点，顶栏分别提供“紫微斗数”“梅花易数”，以及共用的命盘、提示词和设置入口。在同一标签页切换，当前术数单独高亮；不需要打开两份设计稿。没有后台侧栏、工作台、咨询案例、回访和跟进状态。

## 视觉：紧凑的个人排盘工具

保留已确认的现代浅色方向，主色更新为清透翡翠绿。页面上缘仅加低透明度冷绿光感，按钮与品牌使用轻微同色渐变，增加克制的 AI 工具气质；盘面、表单和正文仍保持清晰白底，不增加装饰图案或自动动画。布局秩序保持：导航、页面标题、内容面板与页脚共用左右边界；首页取消重复的排盘标题与说明层级。表单和已有命盘构成一个完整面板，表单使用固定标签列，命盘列表与表单标题上下对齐。

| 元素 | 规范 |
| --- | --- |
| 页面 / 内容底色 | `#F5F8F7` / `#FFFFFF`；命盘栏 `#F8FBF9` |
| 正文 / 次要文字 | `#23332D` / `#6D7C75` |
| 主操作 / 选中背景 | `#087F5B` / `#E8F6EF` |
| 分隔线 | `#E0E9E5` |
| 字体 | 苹方 / 微软雅黑 / 系统无衬线，应用于标题、表单和盘面 |
| 顶栏 | 桌面内容高 48px，手机 46px，另有 1px 底边；品牌 17px、导航 12px |
| 标题 | 首页 20px，其他页面 22px，区块标题 14–15px |
| 阅读字号 | 正文 13–14px，辅助信息 11–12px；手机输入框保持 16px |

首页从“紫微斗数”直接进入新建命盘面板。历法切换与其他输入沿同一控件列排列；排盘规则收在时辰下方，主操作固定在表单底部。右侧列出已有命盘，点开即可查看。

手机将命盘列表接在表单下方，保留标签与控件两列，输入区有一致的起点。梅花可切入独立页；八字、奇门保留禁用占位，手机省略重复“待续”徽标。

十二宫继续使用白底细线；命宫以浅绿提示，四化使用少量红色语义标记。盘面保持主星、辅星、杂曜三级层次。命盘、笔记、设置和弹窗统一使用较小标题、控件与区块间距。

## 可以试的交互

右侧点开一张已有命盘。新表单的生日、性别、时辰为空。示例之外的输入不会伪装成已计算命盘。

盘面可切本命、大限、流年、流月、流日，配合大限/年/月/日下拉选择；保留月份区间与文字盘。点击宫位看完整星曜；“存下这页”独立保存运限，不需要先建任何案例。

“随手记”可写、编辑、删除；笔记留在这张命盘或已保存的运限上。纯盘面复制不会带笔记。“专注看盘”隐藏导航和私人笔记，方便当前设备上展示，不生成公开链接。

“更多”是按钮旁的下拉菜单，可以修改称呼或归档；支持外部点击、Esc 关闭和方向键导航。

提示词支持新建、编辑、副本、删除、变量插入、预览和复制。编辑“本次填写项定义”可增加单行、多行、整数与必填/选填项。自动引用区只显示模板需要的资料，称呼和性别取自所选命盘。本命、定位日完整运限、当前/下一大限、2026/2027/2028 多流年和连续月份均可引用。月份起始为 2026-10/11/12，连续 1–6 个月，支持跨年。必要计算资料或必填项缺失阻断；现实选项选填时明确标为“未提供”。修改上下文后需重新预览。

用户提供的三份完整框架已作为样例模板保留，填写位置改成命名变量。梅花独立入口可带入该次问题和数字；完整卦例模板需要真实上/下卦、本/互/变卦及动爻，当前计算未接入时阻止生成。另有明确命名的“梅花原始起卦请求”，只复制原始问题和数字，不冒充已起卦。八字引用显示未接入，不以紫微四柱替代。

## 示例与运行边界

所有人物、出生资料与笔记都是虚构演示，第一份“我（示例）”并非用户真实资料。星曜和运限由 iztro 2.6.5 及指定技能生成，浏览器不手排星曜。命盘与笔记的新增/编辑只在本次页面内存中保留，刷新重置；提示词正文和填写项定义单独使用当前浏览器 localStorage v2 保存，刷新后仍在；读取 v1 时保留旧模板并补入新样例。本次输入、梅花草稿与展开结果不随模板持久化。浏览器拒绝存储时明确提示仅本次页面保留。均不提交到真实服务。

设计稿只提供有限日期和月份窗口的预生成视图，未实现生产排盘算法。提示词只是纯文本替换，不发送到外部 Agent。规则边界仍以 [紫微规则](../ziwei-rules.md)为准。

重新生成示例数据：

```bash
node docs/design/generate-fixtures.mjs /Users/ximing/.agents/skills/iztro-chart
```

若浏览器或工具限制本地文件访问，可从仓库根目录启动静态预览：

```bash
python3 -m http.server 5193 --bind 127.0.0.1 --directory docs/design
```

打开 `http://127.0.0.1:5193`。没有外部字体、图片或网络 API 依赖。提示词完整需求见 [提示词与命盘引用](../prompt-templates.md)。
