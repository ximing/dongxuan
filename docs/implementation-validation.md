# 本地实现验收记录

日期：2026-11-23。执行：独立 QA SubAgent。对象为 React + Fastify + PostgreSQL 真实站点，`docs/design` 仅作为视觉和交互参照。本次未访问或迁移远程数据库，未发布生产。

## 环境

- 数据库：独立 Docker PostgreSQL，`127.0.0.1:55439`；浏览器使用 `dongxuan_dev`，集成测试使用 `dongxuan_test`。
- API：`http://127.0.0.1:3041`；前端：`http://127.0.0.1:5194`，显式代理到上述 API。没有复用来源不明的 5192 开发进程。
- 账号：通过正常注册流程创建的本地验收账号；数据为合成输入。OIDC 仅由本地脚本关闭，没有业务认证绕过。
- API 已改为 detached 后台运行，PID/log 位于 `apps/server/.runtime.local/`，通过 `node apps/server/scripts/local-env.mjs stop` 停止。
- 前端也以 detached 进程运行，启动参数为 `DONGXUAN_API_TARGET=http://127.0.0.1:3041 pnpm --filter @dongxuan/web dev --port 5194 --host 127.0.0.1`；PID 记录 `apps/web/.runtime.local/web-5194.pid`，日志 `web-5194.log`。停止前先确认 PID 命令属于本项目，可向该独立进程组发 TERM。独立工具调用后两端 `/health` 均通过。
- 本地运行和生产迁移步骤见[本地运行说明](implementation-local.md)。

## 修订与复验

交叉审查发现并已修复：仅引用 `chart.title` 时的档案同人校验、保存视图的查询身份被丢弃、修改参数后旧绑定未清、仅需当前大限却依赖下一大限。前后端均增加相应定向检查。多年月查询有等待状态、防重复提交与过期响应失效处理。

列表分页随后完成前后端闭环：服务端游标绑定账号、来源和筛选条件，保留时间精度；真实 505 条档案分六页回归验证顺序、无重复/遗漏，其他列表也覆盖跨页。浏览器临时创建 51 个独立前缀空档案，搜索首屏显示 50 条，点击“加载更多”后得到 51 条唯一记录并显示已全部载入。验收后仅删除本轮 51 个无任何引用的临时档案，保留一份明确的合成验收档案与示例命盘。来源选择会遍历分页，不再静默限制前 500 项。

最终界面停留在 `http://127.0.0.1:5194/`。顶栏实测为 48px 内容加 1px 边框，主色为 #087F5B。
