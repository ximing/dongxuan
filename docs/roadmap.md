# 实施顺序与验收：个人使用版

## 1. 当前范围

以直接排盘为主，加入轻量笔记。旧方案中的职业工作台、客户/咨询案例/回访流程已撤销。八字、奇门仅占位；梅花先开放独立原始输入与提示词，计算待规则确认。AI 后续再加。

当前状态（2026-11-24）：人物档案已并入命盘。一张命盘就是一个人，称呼、关系和备注记在盘上。下面的历史验收项保留当时的交付记录，不再单独建设档案。

| 阶段 | 交付 |
| --- | --- |
| P0 计算基线 | 先冻结旧 renderer；核实技能口径与边界，开发新计算/文字 |
| P1 稳定命盘 | 快照、迁移、所有命盘入口；旧盘可读且不重算 |
| P2 个人档案 | 首页直接排盘，旁边选人；档案列表和详情，无管理后台 |
| P3 运限与笔记 | 指定日/月查询、独立保存视图、简单笔记 |
| P4 阅读打磨 | 小屏逐宫、文字复制、专注看盘、更多下拉菜单 |
| P5 提示词 | 模板与填写项定义、多来源引用、当前/下一大限、多流年、连续月份、预览复制；梅花独立入口及原始请求 |

P0 可独立开发验证，但新的 renderer 上线等待 P1 完成旧结果重建与切换。笔记和档案不应成为起盘前置条件。

## 2. 验收项

### 排盘首页与输入

- [ ] 打开首页直接出现排盘表单，旁边可选择人物档案。
- [ ] 新建生日、时辰、性别为空；档案缺项带入后仍为空，只填称呼不能生成盘。
- [ ] 明确早子/晚子；钟点与时辰不一致时提示，不伪造分钟。
- [ ] 农历用专属年月日/闰月控件；无效闰月独立校验，不能依赖 iztro 自动容错。
- [ ] 允许不先建档直接起盘，之后再关联人物。
- [ ] 没有工作台、客户、咨询案例、回访任务或职业业务指标。

### 计算与文字

- [ ] 保留冻结 legacy 入口，锁定 iztro 2.6.5，不擅自升级。
- [ ] 已验证场景的星曜、亮度、四化和宫位与参考技能一致。
- [ ] 库内四柱、技能时辰取样的节气四柱分别显示，明确精度与口径。
- [ ] 晚子按实际规则显示；错误和缺失宫位明确失败，不生成假空盘。
- [ ] 童限正确标识，不套用落宫本命的大限区间。
- [ ] 默认闰月十五/十六切换按库实际状态拆段；不复制参考脚本漏分段缺陷。
- [ ] exact 首版不开放；日期区间、出生前和范围外查询有明确校验。

### 保存与迁移

- [ ] 创建基础盘只计算一次，输入、规则、版本、结果和文本事务落库。
- [ ] 详情与列表读取快照，列表不逐盘重新计算。
- [ ] 一个基础快照、多个运限视图均可保存；按准确快照 ID 重开。
- [ ] 预览后版本变化时要求重新预览，不静默保存另一结果。
- [ ] 旧盘回填标记迁移时重建；保留 ID、URL、失败记录和未关联入口。
- [ ] 维护窗口写屏障/不停机双写择一明确实施；旧 NOT NULL 字段兼容写入。
- [ ] 备份恢复、中断重试、数量核对与回滚演练通过。

### 人物档案

- [ ] 称呼、可选关系、出生信息、备注即可建档，不要求联系方式。
- [ ] 资料可不完整；不能推测“自己”关系对应的真实出生信息。
- [ ] 列表可搜索，详情能查看该人的命盘和笔记。
- [ ] 修改人物资料不覆盖旧盘；同名不自动合并。
- [ ] 可归档/恢复；删除流程不会级联丢失盘面和笔记。

### 运限与笔记

- [ ] 指定日显示童限/大限、流年、小限、流月，流日按需开启。
- [ ] 阳历月窗口显示覆盖段、农历标签与实际流月/叠盘范围，去重不丢日期覆盖。
- [ ] `2026-11,2026-12` 普通月份样例和 `2025-08-08/09` 闰月样例均通过。
- [ ] 月窗口部分越界整请求拒绝，说明问题日期段；不静默裁剪。
- [ ] “存下这页”直接保存运限，不要求创建咨询案例。
- [ ] 在人物或具体盘面写笔记，正文可编辑删除，显示创建与更新时间。
- [ ] 笔记的编辑不修改计算快照；不要求判断/反馈分类、状态或修订链。
- [ ] 跨账号不能读写人物、命盘和笔记；双标签页编辑冲突有提示。

### 阅读与展示

- [ ] 桌面完整十二宫；手机支持逐宫与文字阅读，整页不溢出。
- [ ] 纯盘面复制不包含私人笔记。
- [ ] 专注看盘只显示当前盘面，隐藏其他档案与笔记；退出入口明确。
- [ ] 八字、奇门仅显示规划中；梅花有独立入口与原始草稿，前端和 API 都不生成模拟卦。
- [ ] 搜索、空状态、复制失败和保存失败均可理解、可恢复。

## 3. 验证方式

实施时沿用 `pnpm typecheck`、`pnpm test`、`pnpm build`。计算用参考基准与独立边界样例；API 覆盖所有权、快照稳定、笔记更新冲突和迁移幂等。

浏览器主流程变为：“首页选人/填资料 → 起盘 → 看运限 → 存下视图 → 写笔记 → 从人物或全部命盘重开”。不再验收职业咨询流程。

当前业务代码已在隔离本地环境实施，文档与 HTML 原型继续保留为设计依据；实际通过项见[本地实现验收](implementation-validation.md)，生产迁移与发布尚未执行。Review 中的技术发现见 [review-notes.md](review-notes.md)。

## 4. 尚未承诺的能力

精确交节计算、真实支持日期全集、公开分享链接、笔记历史版本、AI、收费与协作均不由当前原型暗示已具备。实施先完成上述明确范围，不为未来术数提前建设后台系统。

## 5. 新增验收：运限与提示词

- [ ] 本命、大限、流年、流月、流日可直接切换，时间选择与盘面层级同步。
- [ ] 保存/重开视图保留当前层级、定位日期与月份参数。
- [ ] 更多为锚定下拉菜单，改名/关联原位编辑，外部点击和 Esc 关闭、方向键导航。
- [ ] 模板按账号与术数存储，支持新建、编辑、副本、删除与更新冲突检查。
- [ ] 命盘入口带入准确的盘和时间参数；引用未保存运限时先用正式预览身份绑定。
- [ ] 未知变量、未声明来源、必要计算资料缺失、必填项缺失、错误括号与部分日期失败明确阻止生成；显式混合来源独立检查绑定。
- [ ] 阳历起始月 + N 个月正确跨年拆流月，去重引用不丢覆盖日期；正式支持上限 12 个月。
- [ ] 改模板、命盘、问题或日期后旧预览与复制失效。
- [ ] 复制前看到完整文本、来源版本和月份覆盖；不自动包含私人笔记。
- [ ] 不自动发送给外部 Agent；复制失败保留手动复制入口。
- [ ] 梅花完整模板缺真实卦例时阻断；独立原始请求只用问题/数字即可复制，不要求紫微盘或生日。
- [ ] 三份用户原文模板保留分析框架；字段定义支持单行/多行/整数及必填策略。
- [ ] 第二份现实选项未填时输出“未提供”并保留先纯看盘再追问约束；当前/下一大限与全部目标流年缺失仍阻断。
- [ ] 月份文本每个覆盖段内部运限恒定，重复段只引用此前完整资料；虚岁和大限变化按段标明。
- [ ] 换人物/命盘清理旧填写；资料来源与模板版本准确标注；不隐式关联同名档案。

详细要求见 [提示词方案](prompt-templates.md)。本次 HTML 可交互样例不替代服务端持久化或完整边界验收。
