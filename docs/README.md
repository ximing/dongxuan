更新：2026-11-23。状态：个人使用版方案与本地实现已接通，尚未发布生产。运行、测试与迁移步骤见[实现说明](implementation-local.md)。

## 当前确认的方向

东玄首先是给自己用的紫微排盘站，也会帮别人看盘。一张命盘就是一个人，不另建人物档案。它不按职业命理师的客户、咨询和回访流程组织。

- 首页直接排盘。旁边列出已有命盘，点开就是这一张。
- 视觉采用现代浅色：白灰底、墨色文字、少量青绿点缀，统一无衬线字体。
- 围绕“命盘 → 运限 → 随手笔记”组织信息。称呼、关系和备注记在盘上。
- 当前只做紫微斗数，参考 [iztro-chart 技能](/Users/ximing/.agents/skills/iztro-chart/SKILL.md)。
- 八字、奇门保留设计占位；梅花有独立入口和原始资料表单，起卦引擎待接入。
- 保留宫位盘、文字盘、大限/流年/流月/流日和简单笔记。
- 保存提示词模板，用占位符引用命盘；支持连续阳历月份自动拆流月，预览后复制给外部 Agent。站内 AI 执行留待后续。
- 模板区分自动关联资料和本次填写项，支持当前/下一大限、多流年；真实实现支持连续 1–12 阳历月，设计稿保留 1–6 月样例。梅花完整卦例与原始起卦请求分开，缺卦象时不生成完整分析提示词。
- 不做工作台、客户管理、咨询案例、待办回访、跟进状态或职业服务工具。

这次定位修正取代此前“专业命理师工作台”的产品假设。之前 review 中与计算、快照和迁移相关的发现仍然有效。

## 核心原则

首页就能起盘。每张命盘就是一个人，称呼、关系和备注记在盘上。笔记可以简单写、简单改，不要求填写咨询主题或跟进状态。

出生资料记在盘上，改正时重算这一张，不另起。展示给别人看时，可以只看当前盘面，不需要引入客户账号或公开分享系统。
