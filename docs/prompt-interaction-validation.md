# 提示词交互优化：业务实现与验收

日期：2026-11-24。范围：实际 React 提示词页面 /prompts，参照[交互提案](prompt-interaction-redesign.md)和[HTML 演示](design/prompt-workbench.html)。

## 已实现

- 默认进入「使用模板」；桌面模板库、填写区、结果区并排。该页面单独放宽到 1440px，导航与内容边界一致，其余页面保持原宽度。
- 模板库显示用途和填写量，支持中文搜索、术数筛选与常用。读取完整分页后筛选，不会遗漏第 51 条以后的模板。
- 模板编辑独立切换，草稿按模板保留。未保存修改不会阻止切换，使用模式始终引用已保存版本；新模板先保存再使用。
- 新建和副本统一对话框；资料支持按中文名称与变量名搜索、按光标插入。填写项自动生成稳定 key，中文改名不影响正文引用，删除同步移除对应引用并可整份撤销。
- 主操作为「生成并复制」，保留「查看预览」。调用真实预览接口、核对当前请求版本及诊断后才允许复制；剪贴板拒绝或超时保留全文和再次复制入口。
- 更改命盘、时间与本次填写时保留上次结果，标为「待更新」并禁止复制；旧请求迟到不能重新启用旧结果。换命盘会清空前一个人的填写与梅花输入绑定。
- 保存视图有明确来源、载入失败重试和「改用基础命盘」。修改时间会解除绑定并提示重新取数。
- 模板保存与预览计算分别管理忙碌状态。保存期间切换到另一模板，不覆盖另一模板的填写与结果。
- 删除放在统一操作菜单中，支持外部关闭、Esc、方向键与焦点恢复；保留确认弹窗。
- 手机采用可横向浏览的模板列表和「填写资料 / 查看结果」切换；成功后进入结果并定位到步骤栏附近，失败留在填写。

模板原文、填写项定义与既有接口保持兼容。生成使用已保存模板的 ID 和 revision，服务端继续检查版本冲突、来源所有权、完整资料和实际时间覆盖；未接入的完整梅花和八字资料仍阻断。

## 状态与保存范围

| 内容 | 保存位置 |
| --- | --- |
| 已保存模板、字段定义 | 原有账号 API 与数据库 |
| 未保存的编辑草稿 | 当前页面内存，离开前需保存 |
| 本次命盘、时间、填写与预览 | 当前页面上下文，不写入模板 |
| 常用标记 | 按账号 ID 隔离的本浏览器存储，只保存模板 ID；存储失败有提示 |

未增加数据库表、迁移或 AI 执行接口。独立 HTML 原型的浏览器存储与业务页面分开。

## 本地真实浏览器验收

使用 Orca 浏览器，对实际页面执行 DOM 交互并调用真实 API；账号、出生资料、问题和新建模板均为独立的合成验收数据。本地前端 5194 代理本项目 3041 API，未使用远程数据库或发布生产。

| 流程 | 结果 |
| --- | --- |
| 流月模板 | 关联真实生成的合成命盘，展开连续三个月资料，得到约 11,836 字符完整文本 |
| 生成并复制 | 真实 Clipboard API 返回成功，页面显示「已生成并复制完整提示词」 |
| 输入变化 | 原结果保留，状态变为待更新，复制禁用 |
| 多年模板 | 当前大限、下一大限和所选流年真实展开；现实选项为空时输出「未提供」 |
| 梅花原始请求 | 问题与 17 / 26 两个整数成功生成原始请求文本 |
| 梅花完整模板 | 未接入卦象时在页面明确阻断，结果不可复制 |
| 多模板编辑 | 切换后恢复未保存草稿；使用模式显示已保存名称和正文 |
| 新建与插入 | 新建副本、自动创建 field_1、修改中文名称、按光标插入资料与填写项成功 |
| 保存与刷新 | 模板正文、字段定义存入数据库；刷新后模板和常用标记仍在 |
| 删除 | 菜单聚焦删除项、Esc 关闭、取消确认保留模板；确认后删除仅本轮临时副本 |
| 保存视图 | 真实保存含流日的指定日视图，提示词显示准确日期；日期控件改为次日后解除绑定并提示基础盘取数 |
| 响应式 | 桌面并排、390px 手机结果、360px 手机编辑均检查无页面横向溢出；实际查看桌面与手机截图 |

剪贴板失败与无响应分支由定向测试覆盖；浏览器成功路径使用真实写入，没有把「生成成功」当作复制成功。新建的临时模板副本已通过页面删除，合成验收命盘与保存视图留在独立本地测试账号下。
