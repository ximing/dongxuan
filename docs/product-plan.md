# 东玄产品方案：个人排盘

## 1. 产品定位

东玄给自己使用，也用于帮熟悉的人看盘。用户有兴趣研究和留记录，但不是以命理咨询为职业。因此，产品应像一册随时能翻开的个人盘簿：打开就排盘，每张命盘就是一个人，想记下的内容有笔记。

首页采用用户明确选择的方式：**直接排盘，旁边打开已有命盘**。不出现工作台、客户管理、咨询案例、回访任务或业务指标，也不再单独做人物档案。

当前只做紫微斗数。八字、奇门仅占位；梅花易数提供独立入口、原始问题/数字表单与提示词，规则未确认前不实现起卦。支持复制提示词供外部 Agent 使用，站内 AI 执行不在当前范围。本文定义目标行为；当前本地工程已接通主要流程，运行与验证范围见[实现说明](implementation-local.md)，不代表已经发布生产。

## 2. 当前基础与改造方向

| 当前实现 | 保留与改造 |
| --- | --- |
| 邮箱密码和可选统一账号登录 | 继续保留，账号只代表使用者本人 |
| 首页输入出生资料，右侧已保存命盘 | 沿用直接排盘的结构；右侧列出已有命盘，点开即可查看 |
| 紫微十二宫和文字盘 | 作为站点中心，补运限和清楚的计算口径 |
| 保存输入，读取时重新计算 | 改为保存结果快照，旧盘不随库升级变化 |
| 新建、复制、删除命盘 | 保留；增加改名、归档、简单笔记与查找 |
| 深色外壳、纸色盘面、朱砂重点色 | 整体替换为现代浅色：白灰底、墨色文字、青绿操作色；统一无衬线字体与紧凑间距 |

源码依据：[首页](../apps/web/src/pages/HomePage.tsx)、[盘面](../apps/web/src/chart/Board.tsx)、[计算](../apps/server/src/chart/render.ts)、[服务](../apps/server/src/chart/chart.service.ts)、[数据表](../apps/server/src/db/schema.ts)。本次没有检查真实用户资料或生产数据库。

## 3. 三个核心对象

| 对象 | 用途 | 首版边界 |
| --- | --- | --- |
| 命盘 | 一个人已经定好的本命，以及上面的运限 | 称呼、可选关系、备注、出生日期、性别、时辰都在这一张盘上 |
| 笔记 | 随手记录看盘想法、背景或后来发生的事 | 正文、时间，挂在这张命盘或一份已保存的运限上；不区分判断/反馈工作流，不要求状态 |
| 提示词模板 | 保存供外部 Agent 使用的指令，并引用盘面变量 | 适用术数、名称、正文、填写项定义与资料要求；预览后复制，展开结果不自动保存到模板 |

同名不自动合并。关系标签“自己”只是这张盘上的备注，不代表登录账号的真实出生信息。

## 4. 日常使用

### 4.1 给自己排盘

打开首页，填出生资料起盘，或点选旁边已有的命盘直接打开。想看某天或某段月份时，在这张本命上切换运限。需要记录想法时，在盘面旁写一条笔记。

生日、时辰和性别初始为空。关系标签“自己”也不允许系统猜测任何出生信息。

### 4.2 帮别人看盘

直接填写对方的称呼和出生资料，排成一张命盘。关系和备注可以随后补在这张盘上。下一次从命盘列表点开，就是这一张。

看盘时可以打开“专注看盘”：扩大当前盘面，暂时隐藏导航和私人笔记。它只是当前设备上的展示方式，不生成公开链接，也不提供对方登录入口。

### 4.3 留下简单记录

背景写在这张命盘的备注或笔记里，已保存的运限上也可以另记想法。笔记可编辑和删除，显示创建与更新时间；不要求追加不可变修订链、咨询主题、结案或回访标签。

出生资料写错时，改正并重算这一张盘，不另起一张。运限上如果已经有笔记，先处理笔记再改。笔记本身仍可编辑。

### 4.4 资料不全与历史盘

排盘时称呼、日期、性别、时辰必须齐全。只写“子时”时要确认早子或晚子，按定下来的那一个时辰排这一张盘。

命盘列表按称呼或关系查找，也可只看已归档。归档用于隐藏不常看的盘，恢复后仍能查看；删除有笔记的盘时需先处理笔记，不能直接级联丢失记录。

## 5. 页面结构

使用同一站点与统一顶栏，品牌后分别提供“紫微斗数”“梅花易数”入口，后接共用的“命盘”“提示词”和轻量设置入口。术数页面在同一标签页切换并准确高亮，不拆成两套设计稿。不做固定后台侧栏。旧的 `/profiles` 地址转到命盘列表。

| 页面 | 内容 |
| --- | --- |
| `/` | 直接排盘；右侧已有命盘；梅花在 header 独立进入；八字、奇门在类型栏显示规划中 |
| `/charts` | 全部命盘、按称呼或关系搜索、归档 |
| `/charts/:id` | 十二宫、文字盘、指定日/月窗口、已保存视图、笔记、称呼与备注 |
| `/meihua` | 独立填写问题与两个数字、可选关联一张命盘、原始草稿、关联提示词；计算待接入 |
| `/prompts` | 模板列表、编辑、变量插入、选择命盘、预览与复制 |
| `/settings` | 现有账号设置及清楚的排盘默认规则 |

不增加案例页面、咨询时间线或专用笔记管理后台。笔记就在这张命盘旁边。

## 6. 排盘与看盘设计

视觉采用用户确认的现代浅色方向：白灰底、墨色文字、少量青绿点缀；页面和盘面统一无衬线字体，收紧标题与字段间距，减少卡片和装饰。具体尺寸与色值见 [设计说明](design/README.md)。

首页由一个完整面板组成：左侧表单采用固定标签列，右侧为已有命盘。两侧标题共用水平基线；导航、页面标题、面板与页脚共用左右边界。顶栏收为 48px，减少重复标题和说明占位。视觉采用翡翠绿主色（#087F5B）、冷白灰底与轻微背景光感，仅在按钮、选中态与品牌处表达克制的 AI 工具气质。点开右侧的命盘直接查看。新的人在左侧填写出生资料排一张。

详情桌面版以完整十二宫为中心，出生资料和四柱放在辅助区。运限采用“本命、大限、流年、流月、流日”明确入口；按所选层级显示大限、年份、月份和日期下拉控件。年月日是定位条件，流月仍按实际引擎状态拆分。保留独立“月份区间”入口。图形盘突出当前层级的宫位映射与流曜，辅助区保留上层背景及四化；文字盘明确标为定位日期完整叠盘。

“更多”在按钮旁展开下拉菜单：修改称呼、关系和备注，改正出生资料，以及归档。改正出生资料和修改称呼都在菜单外的表单里完成，归档直接执行并反馈。点击外部或 Esc 关闭，键盘可导航，不再先弹一个操作列表 modal。

“存下这页”保存当前运限视图，不需要先建案例。可在该视图下写笔记，之后从已保存视图准确重开。纯盘面复制不带入笔记。

手机提供逐宫阅读和文字盘，完整盘可以横向查看。专注模式隐藏导航和笔记，保留明确的退出按钮及当前盘面的必要出生信息。

### 6.1 提示词与外部 Agent

从命盘进入提示词页，带入当前盘及日期/月份范围。模板声明自动资料要求和本次填写项（动作、现状、选项、问题、数字等）；必填与选填分别处理。称呼和性别取自所选命盘，紫微、八字等按显式来源绑定，未接入的计算资料不得替代或编造。支持基准日当前/下一大限、明确的多个流年以及“阳历起始月 + N 个月”，展示实际分段与去重引用。梅花有独立入口：完整分析模板缺卦例时阻止生成，单独的原始请求模板可只复制已填问题与数字。详见 [提示词方案](prompt-templates.md)与[三份实际模板 Review](review-prompt-scenarios.md)。

## 7. 功能需求

| 编号 | 要求 |
| --- | --- |
| FR-01 | 首页直接排盘；旁边的命盘点开即可查看 |
| FR-02 | 称呼、关系和备注记在命盘上，可搜索、可改 |
| FR-03 | 本命图形与文字来自相同结果，分别标注库内四柱与技能取样口径的节气四柱 |
| FR-04 | 查看指定日的童限/大限、流年、小限、流月，按需含流日 |
| FR-05 | 月窗口按实际运限身份分段，处理闰月中途变化，明确范围与重复引用 |
| FR-06 | 出生资料、规则和结果记在这张盘上；改正出生资料重算这一张 |
| FR-07 | 命盘列表按称呼或关系查找，可归档后恢复 |
| FR-08 | 运限视图独立保存，笔记挂在这张命盘或一份已保存的运限上，正文可编辑删除 |
| FR-09 | 复制纯盘面；专注模式不展示导航或私人笔记 |
| FR-10 | 八字、奇门显示规划中；梅花有独立输入入口，计算未接入时不生成模拟结果 |
| FR-11 | 保存与管理提示词正文、填写项定义和资料要求；明确来源，预览后复制给外部 Agent |
| FR-12 | 连续阳历月份引用实际流月分段，支持跨年、重复引用、整段失败提示 |
| FR-13 | 梅花模板独立命名空间；完整卦例与原始请求模板分开，按实际依赖决定是否可生成 |
| FR-14 | 当前与下一大限、多流年与月份资料须完整；现实选项选填时明确标记，保留分阶段追问约束 |

## 8. 当前不做

职业命理师工作台、客户 CRM、咨询案例、回访待办、跟进状态、预约收费、团队协作、客户门户、公开分享、AI 解读、自动断语、自动校时、图片/PDF 报告系统和复杂笔记版本审计。

出生地、真太阳时和海外历史时区暂不参与计算，可写在这张盘的备注里。不能把保存的精确钟点宣传成已经实现分钟级交节精算。

## 9. 成功标准

自己打开首页就能排盘；帮别人看盘时留下一张命盘；之后从列表找回；笔记不用进入咨询流程即可写下；展示盘面时不被后台功能打扰。计算边界和旧盘稳定性按规则文档验收。
